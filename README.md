# HeliOS Releases

HeliOS 데스크톱 앱의 **배포 전용** 저장소입니다. 설치 파일과 자동 업데이트
매니페스트만 올라옵니다 — 소스 코드는 여기에 없습니다.

## 다운로드

[최신 릴리스](https://github.com/alex-hoyeol-choi/helios-releases/releases/latest)에서
받으세요.

| 플랫폼 | 파일 |
|---|---|
| macOS (Apple Silicon) | `HeliOS.dmg` |
| Windows 10/11 (x64) | `HeliOS_*-setup.exe` |

설치 후에는 앱이 새 버전을 자동으로 확인하고 알려줍니다 — 알림에서 버튼 한 번으로
업데이트됩니다.

### 설치 시 참고

- **macOS**: Apple 공증(notarized)을 마친 빌드라 그대로 열립니다.
- **Windows**: 코드서명 인증서 도입 전이라 SmartScreen 경고가 나올 수 있습니다.
  `추가 정보` → `실행`을 눌러 진행하세요.
